# 🎨 دليل تشغيل وفهم نموذج Tiny Retro Diffusion ثنائي اللغة (تحت 100MB)

أهلاً بك يا صديقي البطل! هذا المجلد يحتوي على كامل الكود البرمجي لـ **المشروع الثاني**: بناء، وتدريب، وتشغيل **نموذج توليد صور فن البكسل (Pixel Art) بالكامل من الصفر**، مخصص للغات العربية والإنجليزية، وبأقل استهلاك للموارد والمعالج (CPU) ومناسب للأجهزة والموبايلات الضعيفة!

---

## ⚠️ تنبيه تقني هام جداً بخصوص تشغيل هذا النموذج على برامج التوليد (مثل Local Dream):
برامج توليد الصور محلياً (مثل Local Dream أو KoboldCpp أو stable-diffusion.cpp) مبرمجة ومصممة **بشكل جامد وصلب (Hardcoded)** للتعرف فقط على التنسيقات والطبقات العصبية المحددة لنموذج **Stable Diffusion القياسي** (مثل SD 1.5 أو SDXL).

- **سبب حدوث كراش (Crash) أو تهنيج:**
  بما أن نموذجنا (`bilingual_retro_tiny`) تم بناؤه من الصفر بمعمارية مبتكرة مخصصة فائقة الخفة وبأبعاد دقيقة (64x64)، فإن البرامج القياسية لا تتعرف على أسماء طبقاته المبتكرة، مما يسبب تعارضاً عصبياً في الذاكرة العشوائية للجهاز ويؤدي للتوقف المفاجئ.

- **الحل الأمثل والآمن لك:**
  1. **داخل تطبيق Local Dream:** استخدم دائماً النموذج الأول المكمم وهو **`bk-sdm-tiny_q4_0.gguf`**. هذا النموذج متوافق 100% مع معايير البرنامج ولن يسبب أي كراش نهائياً، ويعطي رسومات ريترو بكسل آرت مذهلة بفضل خفته وتكميمه الاحترافي.
  2. **لتشغيل هذا النموذج المبتكر ذو الـ 80MB:** قم بتشغيله كبيئة مستقلة غاية في السهولة عبر بايثون مباشرة (سواء على هاتفك باستخدام تطبيق Termux أو على أي كمبيوتر ضعيف).

## 🛠️ كيفية تشغيل وتوليد فن بكسل حقيقي عبر بايثون:

### الخطوة 1: تفعيل البيئة الافتراضية
تأكد من تفعيل البيئة الافتراضية الخفيفة التي قمنا بتهيئتها:
```bash
source venv/bin/activate
```

### الخطوة 2: توليد صور ريترو حقيقية مذهلة (Inference)
بمجرد تفعيل البيئة، يمكنك كتابة أي وصف فني باللغة العربية أو الإنجليزية لتوليد صورة بكسل آرت حقيقية ومصقولة بدقة 256x256 (باستخدام خوارزميةNearest Neighbor لضمان جودة فن البكسل الدقيق):

* **التوليد باللغة العربية:**
```bash
python3 generate.py "ماريو بكسل"
```
*(أو "عملة ذهبية ريترو" أو "قلعة ريترو")*

* **التوليد باللغة الإنجليزية:**
```bash
python3 generate.py "pixel knight"
```
*(أو "mario sprite" أو "retro monster")*

سيتم حفظ الصورة الناتجة مباشرة في نفس المجلد باسم **`retro_generated.png`** بجودة بكسل حقيقية رائعة ومحاكية لألعاب الطيبين!
