# 🎮 دليل تدريب وتوليد نموذج Tiny Retro Diffusion الثنائي اللغة من الصفر

أهلاً بك يا صديقي البطل! هذا المجلد يحتوي على كامل الكود البرمجي لـ **المشروع الثاني**: بناء، وتدريب، وتشغيل **نموذج توليد صور فن البكسل (Pixel Art) بالكامل من الصفر**، مخصص للغات العربية والإنجليزية، وبأقل استهلاك للموارد والمعالج (CPU) ومناسب للأجهزة والموبايلات الضعيفة!

---

## 🎨 فلسفة المعمارية والتصميم:
لتحقيق فن بكسل حقيقي (Pixel Art Sprites) وليس مجرد مربعات ضبابية، قمنا بتصميم معمارية مخصصة ومبتكرة للغاية:
1. **ثنائية اللغة المشتركة (Bilingual Latent Space):**
   يحتوي النموذج على طبقة عصبية إسقاطية مشتركة (`BilingualRetroEmbedding`) تقوم بتحليل الكلمات العربية والإنجليزية وربطها بنفس المعنى الفني في الفضاء الكامن (مثلاً: "ماريو" ترتبط مباشرة بـ "Mario"، و"فارس بكسل" بـ "pixel knight").
2. **أبعاد توليد NES/GameBoy دقيقة:**
   يتم توليد الصور وحساب تصفية الضوضاء بأبعاد ريترو حقيقية **64x64** أو **128x128** بكسل، مما يمنع الهلوسة ويضمن تفاصيل متناسقة جداً وبحجم فائق الصغر للنموذج بالكامل (**أقل من 20 ميجابايت!**).
3. **توجيه فائق بالتصنيف الحر (Classifier-Free Guidance - CFG):**
   أثناء التوليد، يتم دمج توقعات النص مع التوقعات الفارغة للحفاظ على التناسق والالتزام الشديد بطلب المستخدم.

## 🚀 كيفية تشغيل وتجربة النموذج خطوة بخطوة:

### الخطوة 1: تفعيل البيئة الافتراضية
تأكد من تفعيل البيئة الافتراضية التي قمنا بتهيئتها في المشروع الأول:
```bash
source venv/bin/activate
```

### الخطوة 2: تدريب النموذج من الصفر (Training)
شغّل سكربت التدريب. سيقوم السكربت تلقائياً بإنشاء مجموعة بيانات ريترو بكسل فنية حقيقية (شخصية ماريو، لويجي، الفارس، الوحش، القلعة، العملة الذهبية) وبألوان ريترو زاهية ودقيقة، ثم يبدأ عملية التدريب العكسي:
```bash
python3 train.py
```
*(سينتج عن التدريب ملف أوزان خفيف جداً باسم `bilingual_retro_tiny.pth`)*

### 3. توليد فن بكسل ريترو جبار (Inference)
بمجرد انتهاء التدريب (أو حتى للتجربة الفورية)، يمكنك كتابة أي وصف فني باللغة العربية أو الإنجليزية لتوليد صورة بكسل آرت حقيقية ومصقولة بدقة 256x256 (باستخدام خوارزمية تكبير بكسل متناسقة Nearest Neighbor):

* **التوليد باللغة العربية:**
```bash
python3 generate.py "ماريو بكسل"
```
*(أو "عملة ذهبية ريترو" أو "قلعة ريترو")*

* **التوليد باللغة الإنجليزية:**
```bash
python3 generate.py "pixel knight"
```
*(أو "mario sprite" أو "retro monster")*

سيتم حفظ الصورة الناتجة مباشرة في نفس المجلد باسم **`retro_generated.png`** بجودة بكسل حقيقية رائعة ومحاكية لألعاب الطيبين!
